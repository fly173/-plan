无人机初步设计工具 0.1.0

适用平台：Windows 10 / 11，64 位。

免安装版：将整个压缩包解压到普通文件夹，双击 UCAVDesigner.exe。
不要只复制 EXE，旁边的 DLL、platforms、translations 等文件也需要保留。
无需安装 Qt Creator、Qt 或 C++ 编译器。

安装版：运行 Setup.exe，完成安装后从桌面或开始菜单启动。
安装程序仅安装到当前用户目录；可以在 Windows 已安装应用中卸载。

打开项目：Ctrl+O；保存项目：Ctrl+S；运行：F5。
建议将自己的 JSON 项目保存到“文档”等个人文件夹。

这是学习用原型，尚未完成论文算例数值一致性验证。
当前发布包未进行代码签名。
