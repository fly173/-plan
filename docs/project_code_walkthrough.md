## 1. 项目整体架构

这个项目大致分成 3 层：

- `src/core`
  放纯计算逻辑。这里不依赖 Qt，主要负责总体参数估算、油耗估算、约束分析。
- `src/ui`
  放 Qt Widgets 图形界面。这里负责窗口、页签、输入框、表格、自定义约束图。
- `tests`
  放一个简单的命令行测试程序，用来验证核心计算层是否正常。

程序运行时的主流程是：

1. `main.cpp` 启动 Qt 应用。
2. `MainWindow` 创建主窗口界面。
3. 用户在界面里输入参数并点击按钮。
4. `MainWindow` 从界面里读取数据，调用核心计算类。
5. `WeightAnalysis` 计算最大起飞重量、空重、燃油分数等。
6. `ConstraintAnalysis` 计算约束曲线和推荐设计点。
7. `MainWindow` 把结果写回标签、表格和图形控件中。

## 4. 这些部分是怎么串起来的

你可以把整个程序理解成下面这条流水线：

1. `main.cpp` 启动 Qt
2. `MainWindow` 创建窗口、页签、输入框、表格和绘图控件
3. `loadDefaults()` 把默认值写进界面
4. 用户修改参数后点击 `Run Sizing`
5. `runCalculation()` 把界面数据读成结构体
6. `WeightAnalysis::solve()` 计算重量结果
7. `ConstraintAnalysis::solve()` 计算约束曲线和推荐设计点
8. `showWeightResult()` 把重量结果写到标签和表格
9. `ConstraintPlotWidget::setConstraintResult()` 接收曲线并准备重绘
10. `paintEvent()` 真正把图画出来
11. 用户点击图后，`mousePressEvent()` 发出 `designPointSelected(...)`
12. `MainWindow::handleDesignPoint()` 再根据这个点计算并显示裕度

## 5. 这个项目里最值得先掌握的 Qt 概念

如果你正拿这个项目学 Qt，建议先抓住下面几个关键词：

- `QApplication`
  整个 Qt 程序的运行环境和事件循环入口
- `QMainWindow`
  主窗口
- `QWidget`
  几乎所有界面控件的基础类
- Layout 布局
  `QVBoxLayout`、`QHBoxLayout`、`QFormLayout` 决定控件怎么摆
- 信号与槽
  `connect(...)` 决定“用户做了什么后，代码应该执行什么”
- `QPainter`
  用来做自定义绘图
- `QJsonDocument / QJsonObject / QJsonArray`
  用来做 JSON 保存与导入

## 6. 哪些文件先不要拿来学

下面这些文件虽然真实存在，但不适合你一开始就研究：

- `CMakeLists.txt.user`
  这是 Qt Creator 在本机保存的工程配置缓存
- `build/` 和 `build_ascii/`
  这是构建生成目录，不是你手写的程序逻辑
- Qt 自动生成的 MOC 文件
  这些是构建系统根据头文件自动生成的
- 部署出来的 DLL 和插件目录
  这些是运行依赖，不是项目业务代码

先把“手写源码”看懂，再回头看这些自动生成内容，会轻松很多。
